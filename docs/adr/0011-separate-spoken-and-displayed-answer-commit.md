# 分開記錄已播語音與已顯示看板項目

按需看板回答由數字人口述摘要，具體項目由控制台與舞台顯示。使用者已確定需要針對看板內容追問，因此正式整合方向是將已播語音與已顯示看板項目分開記錄，共同提供後續對話上下文；將所有內容塞進 `played_text` 會破壞其「已出聲」的意義，而僅保留語音則無法理解「第二點詳細說明」。

此方向已完成實作。現行 [ADR 0007](0007-stream-replies-with-turn-isolation-and-audio-clock.md) 與 [ADR 0010](0010-console-rest-state-follows-turn-commit.md) 的語音提交保證繼續有效；看板項目則以顯示確認事件獨立提交，發送、顯示與閱讀不混為一談。

## Consequences

- 口語／看板分流在後端、語意切片與 TTS 入列之前完成，串流與舊有回覆模式均須涵蓋。
- 已顯示的完整項目可供追問；插話後保留已顯示內容，尚未顯示的舊輪次內容丟棄。看板收合只改可見性，清空對話才移除該場對話的看板上下文。
- 每個 presenter 以項目識別碼確認顯示，重送時可去重；只有確認顯示的完整項目會寫入該場對話上下文。
- 看板失敗保留可用摘要與已顯示項目並支援重試；不自動把全部細節送入 TTS。
- [完成規格](../../.scratch/answer-board/spec.md) 記錄已交付行為與自動驗證範圍。
