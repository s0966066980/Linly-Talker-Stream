# 以完整可播回覆片段維持有界舞台字幕窗口

數字人舞台採用可由控制台調整的「舞台字幕顯示上限」，預設 120、允許 20–2000 字，並與 LLM 回覆生成上限分離。舞台只在已播回覆片段提交後累積內容；超過上限時淘汰最早的完整片段，同一輪次內維持最新內容，控制台與對話歷史仍保留完整回覆。

## Considered Options

- 無界累積並依賴 CSS 捲動：拒絕，舞台會逐漸被舊字幕佔滿，且顯示進度不再是清楚的即時窗口。
- 以字元硬切最前方內容：拒絕，會破壞可播回覆片段的語意邊界，並讓字幕顯示與播放提交責任不一致。
- 重用 LLM 的回覆生成上限：拒絕，會把模型回答長度與舞台呈現容量綁在一起，造成設定意義混淆。

## Consequences

- 舞台必須依對話輪次保存完整片段邊界，以 Unicode 使用者感知字元計算窗口大小。
- 設定是後端共用且可持久化的舞台設定；獨立舞台設定分頁與獨立套用操作，下一輪生效，舞台可沿用既有週期同步機制取得更新。
- 單一片段超過上限時保留完整片段，因此上限是片段邊界的近似上限；淘汰只發生在新片段播放提交之後。
- 舞台可對淘汰片段做短暫淡出／上移，但不得延遲音訊或影像輸出；輪次取消、斷線與重連時清空窗口。
