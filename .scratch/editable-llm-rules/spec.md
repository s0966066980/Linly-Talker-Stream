# 單一 LLM 可編輯回覆規則 v1 完成規格

Status: completed

## 已交付行為

- 控制台提供看板啟用、口語回答與看板內容三段自然語言規則。
- 載入、編輯、還原預設與「儲存並套用」均以同一版本快照操作；版本衝突回傳 409，不覆蓋較新設定。
- 規則整組驗證並原子保存；失敗時保留草稿與上一份生效規則。
- 每輪開始時擷取不可變規則快照，輪次途中修改只影響下一輪。
- 自訂規則持久化至 runtime overrides，且不覆蓋其他 LLM 或舞台設定。
- 協定標記與輸出格式由系統固定管理，不開放規則內容破壞；看板本文不送入 TTS。

## 預設語意

- 問候、簡單確認、單一事實與可簡短口述的問題使用簡答。
- 有兩個或以上彼此獨立的重點，且需要分項閱讀時使用看板。
- 看板回答先口述主要結論，再以項目補充具體資訊；不逐項朗讀。
- 使用者本輪明確的呈現要求可調整預設選擇，但不能覆寫功能開關或固定協定。

## v1 驗收

- Python 規則、持久化、版本衝突、輪次快照與協定測試通過。
- Web 規則編輯器的載入、dirty state、套用、衝突與還原測試通過。

設計決策見 [ADR 0012](../../docs/adr/0012-editable-rules-for-single-llm.md)。
